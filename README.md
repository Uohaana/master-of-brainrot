# Chaos Club

A meme-powered landing page with a loud personality, creative energy, and a brand voice that is impossible to ignore.

## Quick start

```bash
git clone https://github.com/Uohaana/master-of-brainrot.git
cd master-of-brainrot
```

Then serve the project locally:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Features

- Bold, internet-native visual identity
- Multiple pages for branding, gallery, and contact
- Meme-driven copy and gallery interactions
- Lightweight static setup with no framework overhead
- Designed to feel memorable instead of generic

## Why it exists

This project is built for personality first. The point is not to feel balanced or corporate. The point is to be instantly recognisable, playful, and a little chaotic in the best possible way.

It is a reminder that not every web project needs to look sterile. Some of them should feel alive.

## Local run

### Requirements

- Python 3.x
- Modern browser

### Start locally

```bash
python -m http.server 8000
```

## How it works

This is a static HTML, CSS, and JavaScript project designed for speed and visual punch. The page uses a lightweight structure, playful content, and dynamic sections to create a high-energy experience without adding framework complexity.

The result is a page that is easy to run, easy to modify, and very easy to remember.
