# Chaos Club

A meme-powered creative brand landing page that turns internet chaos into a bold, memorable digital identity.

![Chaos Club preview](https://api.memegen.link/images/drake/son/sigma.png)

## Try it locally

Open the site in your browser from the project folder, or serve it locally with:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Quick start

```bash
cd "C:\Users\USER\Desktop\hack club"
python -m http.server 8000
```

Open `http://localhost:8000` in a browser to view the site.

## Features

- Bold landing-page design built around meme culture and internet energy
- Multiple branded pages for home, gallery, about, and contact
- Interactive meme phrase generator for extra personality
- Gallery of meme-style visuals that matches the brand's chaotic aesthetic
- Lightweight static setup with zero framework overhead

## How it works

This project is a deliberately unapologetic static website: plain HTML, CSS, and JavaScript are used to create a fast, flexible experience with strong visual identity and minimal setup friction. The design leans into humor, contrast, and chaotic branding instead of trying to look corporate or polished in the traditional sense.

The JavaScript enhances the landing page with rotating meme text and dynamically rendered gallery cards, which gives the site more personality without making it harder to run or maintain.

## Project structure

- `index.html` – home page and primary marketing content
- `about.html` – brand story and positioning
- `gallery.html` – meme gallery layout
- `memes.html` – additional meme-focused showcase
- `contact.html` – contact page
- `styles.css` – styling, layouts, and theme treatment
- `main.js` – meme phrase rotation and gallery generation

## Local run instructions

This project does not require a framework or package install. A basic Python web server is enough.
