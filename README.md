# Chaos Club

A meme-powered static landing page and gallery for a fictional creative brand called Chaos Club. The site is built with plain HTML, CSS, and JavaScript and is designed to feel chaotic, bold, and internet-native.

## Highlights

- Bold single-page marketing layout
- Meme-inspired branding and typography
- Gallery and meme generator interactions
- Responsive static site with no framework required

## Project structure

- `index.html` – landing page
- `about.html` – brand story and positioning
- `contact.html` – contact section
- `gallery.html` – meme gallery
- `memes.html` – additional meme showcase
- `styles.css` – visual styling and layout
- `main.js` – interactive meme phrase and gallery rendering

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This project is a lightweight static website for creative branding experimentation and meme-heavy visual storytelling.
